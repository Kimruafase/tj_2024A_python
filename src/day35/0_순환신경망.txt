[순환신경망]
    > Recurrent Neural Network
    > 컴퓨터가 데이터를 기억하고, 앞에서 받은 정보를 활용하여 다음에 어떤 결과가 나올지 예측하는 딥러닝 모델
    > ex_ "나는 오늘" 이라고 했을 때 다음에 나올 단어를 예측한다면 RNN은 앞에서 받은 정보를 기억하여 "공부" "여행" 같은 단어를 예측한다.
    > CNN(합성곱) vs RNN(순환신경망)
        > CNN : 1. 이미지(2차원 데이터) 2. 특징(색상, 모양) 찾기 3. 이미지 분석하여 이미지 분류 4. 순서 상관 없이 데이터 입력
        > RNN : 1. 텍스트, 음성(1차원 데이터) 2. 이전 데이터를 기억해서 다음 데이터를 예측 3. 문장 만들기 4. 순서(시계열 / 시간) 유지하면서 데이터 입력

[SimpleRNN]
    > 가장 기본적인 단일 순환신경망 구조
    > 동작 구조 : 계산 처리된 데이터를 받아서 다음 계산으로 전달하는 구조

[LSTM]
    > Long Short - Term Memory
    > 중요한 정보는 오래 기억하고, 덜 중요한 정보는 잊어버리는 방법
    > 사용처 : 많은 데이터와 데이터를 오래 유지할 때 사용, 긴 문자열, 감정 분석 등등
    > 동작 구조 : 3가지의 게이트(망각, 입력, 출력)가 존재한다.
        > 망각 게이트 : Forget Gate, 필요 없다고 생각하는 데이터를 잊어버릴지 결정하는 게이트(Sigmoid 함수를 사용해서 0 -> 망각, 1 -> 기억)
        > 입력 게이트 : Input Gate, 현재 데이터를 전달받아 계산을 통해 Sigmoid 함수의 결과에 따라 상태를 더할지 말지 결정하는 게이트
        > 출력 게이트 : Output Gate, 출력값을 결정하고 오랫동안 기억하는 게이트

[GRU]
    > Gated Recurrent Unit
    > LSTM과 마찬가지로 중요한 정보는 오래 기억하고, 덜 중요한 정보를 잊어버리는 방법
    > LSTM보다 더 간단한 구조이며 빠르다.
    > 사용처 : 조금 더 적은 데이터와 빠른 속도가 필요할 때 사용, 실시간 처리, 모바일
    > 동작 구조 : 2가지의 게이트(Update, Reset)가 존재한다.
        > 업데이트 게이트 : 출력 / 입력 게이트 모두 제어, 새로운 데이터를 얼마나 기억할지 or 잊을지 결정하는 게이트
        > 리셋 게이트    : 이전 데이터를 얼마나 반영할지 결정하는 게이트

[계산식 기호]
    > h : 현재 시점의 상태값
    > x : 현재값
    > W : 현재 시점의 가중치
    > U : 이전 출력에 대한 가중치
    > t : 시간 순서
    > F : 망각 게이트 (정보를 기억할지 말지 결정)
    > I : 입력 게이트 (새로운 정보를 더할지 말지 결정)
    > O : 출력 게이트 (최종 출력 결정)
        > Sigmoid (0 or 1 값을 출력해서 게이트를 열지 말지 사용되는 함수)
        > 하이퍼볼릭 탄젠트 (데이터를 -1 ~ 1 사이 값으로 반환하는 함수)
    > Z : 업데이트 게이트 (현재 입력을 얼마나 기억할지 결정)
    > R : 리셋 게이트 (이전 데이터를 얼마나 기억할지 결정)

[임베딩]
    > 컴퓨터가 글자나 단어를 숫자로 변환하여 컴퓨터가 이해하고 처리할 수 있도록 하는 방법
    > One - Hot 인코딩 : 현재 단어의 위치를 1로 표현하고 다른 단어를 0으로 표현하는 방법
        > ex_ 나는[1, 0, 0] 딥러닝이[0, 1, 0] 재미있다[0, 0, 1]
            > 문제점 : 문장이 길어지면 대부분이 0으로 채워져서 희소행렬이 되어 메모리 낭비와 유사도를 알기가 어렵다.
    > 밀집행렬 : 0이 아닌 실수값을 채워서 표현, 메모리 낭비가 적고 단어의 유사도를 알 수 있다.(Keras API가 사용)
    > 임베딩 레이어

[양방향 RNN]
    > 데이터를 앞에서부터 읽으면서 또한 뒤에서부터 읽는 양방향 RNN 신경망
    > 순차적인 RNN은 앞에 있는 데이터를 보고 예측하지만 양방향 RNN은 앞뒤 데이터를 보고 예측한다.
    > ex_ "나는 밥을 먹었다." 라는 문장을 학습할 때 "나는" 과 뒤에 있는 "먹었다"를 학습하면서 "밥"이라는 단어를 예측

[유닛]
    > CNN의 뉴런(노드)과 비슷한 역할을 한다. 뉴런 == 유닛
    > LSTM layer는 여러개의 유닛(뉴런)으로 구성되고 각 유닛(뉴런)은 입력을 처리하고 출력하는 역할
    > 유닛 개수가 32개면 32개의 독립적인 유닛(뉴런)을 통해 각 데이터를 처리하고 패턴을 학습한다.
        > 유닛 개수가 많으면 더 많은 학습과 표현이 향상되지만 과대적합이 발생할 수 있다. 적절한 유닛 개수 사용(32, 64, 128 주로 사용)

[스태킹 RNN]
    > 여러 RNN Layer로 쌓은 순환신경망 구조, 복잡한 패턴 학습 가능
    > 기본적으로 RNN은 마지막 상태값만 출력하기 때문에 앞에 출력상태는 무시하게 된다.
    > return_sequences 속성을 True로 설정하여 layer를 쌓을 수 있다.

[순환 드롭아웃]
    > 드롭아웃 : 훈련 과정 중에 일부 유닛(뉴런)을 무작위로 선택하여 비활성화하여 학습을 하지 않는 유닛(뉴런) 구성
    > 목적 : 과대적합을 방지하고 무작위를 이용한 다양한 학습을 하여 일반화된 성능을 향상시킬 수 있다.
    > 순환 드롭아웃 : RNN에 드롭아웃 적용
        > recurrent_dropout : 순환 상태의 데이터에 적용, 이전 순환 상태의 출력된 데이터에 대해 무작위로 비활성화
        > dropout           : 입력(새로운) 데이터에 적용되며, 전체 입력 유닛(뉴런)을 무작위로 비활성화
